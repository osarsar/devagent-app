Outils de développement
Utilisées par l'onglet « Développer » de chaque projet. Vide = valeur par défaut.
GitHub
Cree un token : GitHub > Settings > Developer settings > Personal access tokens > Tokens (classic) > Generate new token (repo scope)
Repos GitHub
Configure ton token pour voir tes repos
Cloudflare R2
Cloudflare Dashboard > R2 > Manage R2 API Tokens > Create API Token
Buckets R2
Configurez les identifiants R2 pour voir vos buckets
